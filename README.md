# 917869

《917869》是一款基于 4×4 棋盘的数字合成小游戏。

通过滑动棋盘，让数字按照不同方向和碰撞顺序发生合成，逐步完成三个阶段的挑战。

当前版本：`v1.0.0`

## 开始游戏

### 拆分版

打开 [index.html](index.html) 即可游玩。

如果浏览器限制本地文件运行，也可以启动本地静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

### 单文件版

打开 [917869-advanced.html](917869-advanced.html) 即可游玩。

单文件版不需要额外目录或构建工具，适合直接分享和保存。

## 基本玩法

- 棋盘大小为 4×4。
- 游戏会生成 6、7、8 等基础数字。
- 使用方向键或滑动棋盘移动数字。
- 合成结果取决于移动方向和数字碰撞顺序。
- 没有定义合成规则的碰撞会使数字消失。

## 挑战目标

游戏分为三个阶段：

1. 第一阶段：在同一横排完成普通的 `91、78、69`。
2. 第二阶段：在同一横排完成二阶的 `91、78、69`。
3. 第三阶段：在同一横排完成三阶的 `91、78、69`。

完成第三阶段后即可通关。

## 游戏内容

- 新手教程
- 三阶段挑战
- 成就系统
- 隐藏彩蛋路线
- 本地排行榜
- 本地存档
- 存档导出与导入
- 中英文界面

```bash

```
